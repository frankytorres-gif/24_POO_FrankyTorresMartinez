# Agenda de Contactos MVC

## Descripción
Aplicación de consola desarrollada en Java bajo la arquitectura Modelo-Vista-Controlador (MVC) para la gestión de una agenda de contactos.

## Funcionalidades
- **Registrar contacto**: Permite ingresar un nuevo contacto con nombre, teléfono y email.
- **Listar contactos**: Muestra todos los contactos registrados y cargados en memoria.
- **Buscar contacto**: Busca un contacto específico por su nombre.
- **Eliminar contacto**: Elimina un contacto registrado en el sistema.
- **Carga inicial de datos**: Incluye 5 contactos de prueba predeterminados.
